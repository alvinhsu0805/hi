# 工廠不良表單 OCR 自動登打（QWF-ME061）

對應 AMT「外觀檢驗暨首件檢查表」紙本：拍照後辨識型號／批號／作業人員與各不良代碼數量，審核後寫入 Excel。

## 看了你的樣張後：OCR 可不可行？

**可行。** 而且這張表比「整張只靠正字畫」更適合做自動登打。

| 區塊 | 樣張內容 | 辨識策略 |
|------|----------|----------|
| 表頭 | 型號 `10819-B`、批號 `26-06-209`、人員 `12449/12129`、規範 `A001-3` | Vision 讀手寫／印刷欄位 |
| 底部不良數 | 各欄阿拉伯數字（樣張加總約 15） | **主路徑**：對齊代碼讀數字 |
| 總計 | 總數 142、總不良 15、總良 127 | 讀取並與各欄加總交叉驗證 |
| 格子劃記／正字畫 | AA／非AA 區藍筆劃記 | 僅在底部空白時當備援 |
| 大字備註 | 如「不平」「水痕」 | 進 `hand_notes`，不當代碼數量 |

重點：你們表上已經有底部「不良數」與「總不良數」，**優先讀這些數字**，比逐格數正字畫穩很多。潦草仍可能錯，所以保留審核頁。

## 快速開始

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=sk-...    # 建議啟用真實讀圖
python main.py init
python main.py serve            # http://127.0.0.1:8000
```

示範模式（無 API Key）可用檔名含 `amt` / `qwf` / `sample` 載入樣張表頭與合計，方便先串 Excel。

## Excel 輸出

`data/outputs/defect_stats.xlsx`

- **檢驗日結**：一張表單一列（表頭 + 總計 + 全部不良代碼欄）
- **不良明細**：只列 count>0 的代碼，方便樞紐

不良代碼定義在 `config/defect_schema.json`（P / PB01–23 / GB01–16 / FA01–14）。若你們有正式代碼中文名稱表，把各項目的 `label` 改掉即可。

## 拍照建議（依你這張表）

1. 整張入鏡，尤其底部合計列要清楚  
2. 壓平、避免反光與大片陰影  
3. 手寫數字盡量寫在「不良數」格內  
4. 跨欄大字備註可保留，系統會當備註
